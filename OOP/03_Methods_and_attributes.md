# Тема 3. Методы и атрибуты.

### 1. Введение

В прошлом уроке мы создали класс `Animal`, который имел атрибуты `name`, `age`, `favorite_food`. Мы могли создавать объекты и читать/изменять их атрибуты напрямую:

```python
animal = Animal("Симба", 5)
animal.age = 6                  # изменили возраст
print(animal.favorite_food)     # []
```

Но это неудобно и небезопасно: любой может изменить данные как угодно, а логика поведения (например, кормление) остаётся за пределами класса.

**Что мы хотим?**  
Чтобы объект **сам** умел делать что-то полезное: издавать звук, кушать, сообщать свой возраст. Для этого в класс добавляют **методы** — функции, которые принадлежат объекту и имеют доступ к его данным через `self`.

Кроме того, атрибуты бывают не только у каждого объекта (экземпляра), но и общие для всех объектов класса — это **атрибуты класса**.

---

### 2. Атрибуты экземпляра и атрибуты класса

До сих пор мы создавали атрибуты через `self` внутри `__init__` — это **атрибуты экземпляра** (у каждого объекта свои значения).  

Но иногда нужно хранить данные, общие для **всех** объектов класса. Например, для всех животных максимальный возраст или список всех созданных особей. Такие данные хранятся в **атрибутах класса** — они определяются прямо в теле класса, вне методов.

#### 2.1. Типы атрибутов

- Атрибуты экземпляра: уникальны для каждого объекта.
- Атрибуты класса: общие для всех экземпляров.

#### 2.2. Атрибуты экземпляра

> Атрибуты экземпляра: переменные, которые хранят данные конкретного объекта. Обычно создаются в `__init__` через `self.имя = ...`.

```python
class Animal:
    def __init__(self, name, age):
        # Атрибуты экземпляра
        self.name = name
        self.age = age

# Создаём два разных объекта
animal1 = Animal("Симба", 5)
animal2 = Animal("Кеша", 7)

# У каждого объекта свои значения атрибутов
print(f"{animal1.name}: {animal1.age} лет")     # Симба: 5 лет
print(f"{animal2.name}: {animal2.age} лет")     # Кеша: 7 лет
```

#### 2.3. Атрибуты класса

> Атрибуты класса: переменные, объявленные прямо в теле класса (вне методов). Они общие для всех экземпляров.

```python
class Animal:
    # Атрибут класса: общий для всех экземпляров
    max_age = 30    # все животные живут не больше 30 лет
    
    def __init__(self, name, age):
        # Атрибуты экземпляра: у каждого животного свой
        self.name = name
        self.age = age

# Создаём два разных объекта
animal1 = Animal("Симба", 5)
animal2 = Animal("Кеша", 7)

# У каждого объекта свои значения атрибутов
print(f"{animal1.name}: максимальная продолжительность жизни {animal1.max_age} лет")     # Симба: макс... 30 лет

# Меняем атрибут класса: это видят сразу все экземпляры
Animal.max_age = 35

print(f"{animal1.name}: максимальная продолжительность жизни {animal1.max_age} лет")     # Симба: макс... 35 лет
print(f"{animal2.name}: максимальная продолжительность жизни {animal2.max_age} лет")     # Кеша: макс... 35 лет
```

#### 2.4. Зачем нужны атрибуты класса?
- Хранить константы (например, `pi`).
- Счётчики объектов (сколько создано экземпляров).
- Общие настройки для всех экземпляров.

Покажем счётчик:

```python
class Animal:
    count = 0   # счётчик созданных животных

    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.favorite_food = []
        Animal.count += 1   # увеличиваем счётчик при каждом создании

print(Animal.count)   # 0
a1 = Animal("A", 1)
a2 = Animal("B", 2)
print(Animal.count)   # 2
```

#### 2.5. Когда какой атрибут использовать?
- Атрибуты экземпляра: для данных, которые различаются между объектами (имя, возраст, id).
- Атрибуты класса: для:
   - Констант и значений по умолчанию;
   - Данных, общих для всех экземпляров (например, имя школы для всех студентов);
   - Счётчиков уровня класса (например, сколько объектов уже создано).

### 3. Методы экземпляра

#### 3.1. Типы методов

В Python есть несколько видов методов:

- Обычные методы (методы экземпляра): работают с конкретным объектом через `self`.
- Методы класса: работают с классом в целом, получают `cls`.
- Статические методы: не получают ни `self`, ни `cls`.
- Магические/специальные методы: имеют особое значение для Python (например, `__init__`, `__str__`).

#### 3.2. Обычные методы

> Обычные методы: функции внутри класса, принимающие self первым параметром. Через self обращаются к атрибутам объекта и вызывают другие методы.

Вернёмся к нашему классу `Animal` и добавим метод `say_hello`:

```python
class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.favorite_food = []

    def say_hello(self):
        print(f"Привет! Я {self.name}, мне {self.age} лет.")
```

Теперь создадим объект и вызовем метод:

```python
simba = Animal("Симба", 5)
simba.say_hello()   # Привет! Я Симба, мне 5 лет.
```

**Что произошло:**  
- `simba.say_hello()` превратился в вызов `Animal.say_hello(simba)` (Python сделал это за нас).  
- Внутри метода `self` указывает на `simba`, поэтому `self.name` — это `"Симба"`.

> Также методы могут принимать дополнительные аргументы и возвращать результат, как обычные функции.

Добавим метод `feed`, который принимает еду и добавляет её в список любимых, а также метод `is_favorite_food`, который возвращает `True`, если есть любимая еда:

```python
class Animal:
    # ... __init__ и say_hello ...

    def feed(self, food):
        self.favorite_food.append(food)
        print(f"{self.name} съел {food}.")

    def is_favorite_food(self):
        return len(self.favorite_food) > 0
```

Использование:

```python
simba.feed("мясо")                  # Симба съел мясо.
print(simba.is_favorite_food())     # True
```

**Важно:** методы могут изменять состояние объекта (например, добавлять элементы в список) и возвращать новые данные.

#### 3.3. Методы класса

> Методы класса: получают сам класс первым параметром (обычно называется cls), а не экземпляр. Декорируются через @classmethod. Часто используются как альтернативные конструкторы.

```python
class Animal:
    count = 0
    
    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.favorite_food = []

    @classmethod
    def get_count(cls):
        return cls.count
```

Вызов:

```python
# Создаём два разных объекта
animal1 = Animal("Симба", 5)
animal2 = Animal("Кеша", 7)

# Выводим результат
print(Animal.get_count())   # 2
```

#### 3.4. Статические методы

> Статические методы: не получают ни self, ни cls. Декорируются через @staticmethod. Используются для вспомогательных функций, логически связанных с классом, но не требующих доступа к его состоянию.

```python
class MathUtils:
    @staticmethod
    def is_prime(number):
        """Проверяет, является ли число простым"""
        if number < 2:
            return False
        for i in range(2, int(number**0.5) + 1):
            if number % i == 0:
                return False
        return True
```

Вызов:

```python
# Вызываем статический метод через имя класса
print(f"Является ли 7 простым числом: {MathUtils.is_prime(7)}")     # Является ли 7 простым числом: True
print(f"Является ли 10 простым числом: {MathUtils.is_prime(10)}")   # Является ли 10 простым числом: False
```

#### 3.5. Магические/специальные методы

> Специальные методы: методы с двойными подчёркиваниями в имени (__init__, __str__, __add__, __eq__). Python вызывает их сам при определённых операциях: создание объекта, печать, сложение, сравнение.

Мы уже упоминали, что при `print(объект)` выводится что-то некрасивое. Для удобства добавим метод `__str__`, который возвращает строку с описанием объекта:

```python
class Animal:
    # ... другие методы ...

    def __str__(self):
        return f"Животное {self.name}, возраст {self.age}"
```

Вызов:

```python
print(simba)   # Животное Симба, возраст 5
```

Часто используемые специальные методы:

| Метод                           | Описание                                 | Пример использования  |
|---------------------------------|------------------------------------------|-----------------------|
| `__init__(self, ...)`           | Конструктор                              | 	obj = MyClass()      |
| `__str__(self)`                 | Строковое представление для пользователя | 	print(obj)           |
| `__repr__(self)`                | Строковое представление для разработчика | 	repr(obj)            |
| `__len__(self)`                 | Длина объекта                            | 	len(obj)             |
| `__getitem__(self, key)`        | Доступ по ключу/индексу                  | 	obj[key]             |
| `__setitem__(self, key, value)` | Присваивание по ключу/индексу            | 	obj[key] = value     |
| `__call__(self, ...)`           | Вызов объекта как функции                | 	obj()                |
| `__add__(self, other)`          | Оператор +                               | 	obj + other          |
| `__sub__(self, other)`          | Оператор -                               | 	obj - other          |
| `__eq__(self, other)`           | Оператор ==                              | 	obj == other         |
| `__lt__(self, other)`           | Оператор <                               | 	obj < other          |

### Распространенные ошибки

| Ошибка                                   | Пояснение                                                                                       | Решение                                                                                                 |
|------------------------------------------|-------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|
| Забыли `self` в определении метода       | Метод без `self` будет работать как обычная функция, но не получит доступ к объекту             | Всегда указывайте `self` первым параметром                                                              |
| Пытаетесь вызвать метод без объекта      | `Animal.say_hello()` выдаст ошибку, т.к. не передан `self`                                      | Создайте объект и вызовите через него, либо используйте `Animal.say_hello(simba)` (но так редко делают) |
| Путаете атрибут класса и экземпляра      | При изменении атрибута через объект создаётся новый атрибут экземпляра, а не меняется классовый | Если хотите изменить классовый атрибут, используйте `ClassName.attr = value`                            |
| Используете `self` вне метода            | `self` имеет смысл только внутри методов экземпляра                                             | Вне методов используйте имя класса или конкретный объект                                                |
| Возвращаете результат, но не используете | Метод может вернуть значение, но если его не присвоить переменной, оно потеряется               | Сохраняйте результат: `result = obj.method()`                                                           |

### Краткий итог

- **Методы экземпляра** — это функции внутри класса, которые получают `self` и могут читать/изменять атрибуты конкретного объекта. Просто говоря - **это действие объекта**.
- **Атрибуты экземпляра** — уникальны для каждого объекта, создаются через `self` (обычно в `__init__`). Просто говоря - **это характеристики объекта**.
- **Атрибуты класса** — общие для всех объектов, определяются прямо в классе.
- Существуют также **методы класса** (`@classmethod`) и **статические методы** (`@staticmethod`), но они нужны реже, с ними познакомимся позднее.
- Мы научились добавлять поведение объектам, что делает код более логичным и безопасным.

**1. Каким образом можно получить доступ к атрибуту экземпляра из метода этого же класса?**

А) По имени атрибута напрямую, например `age`.  
Б) Через параметр `self`, например `self.age`.  
В) Через имя класса, например `MyClass.age`.  
Г) Только через геттеры и сеттеры.

**Правильный ответ:** Б

**2. Что произойдёт при попытке обратиться к атрибуту экземпляра, который не был определён ни в `__init__`, ни позже?**

А) Будет возвращено значение `None`.  
Б) Будет создан новый атрибут автоматически.  
В) Будет возбуждено исключение `AttributeError`.

**3. Пусть у класса есть атрибут `value = 5`. Если создать два экземпляра (`obj1`, `obj2`) и изменить `value` через один из них (`obj1.value = 10`), то как это повлияет на другой экземпляр и на сам класс?**

А) Изменится значение у класса и у всех экземпляров.  
Б) Будет ошибка, так как атрибут класса нельзя изменять через экземпляр.
В) Изменится у `obj1` и у класса, но не у `obj2`.  
Г) Изменится только у `obj1`, у `obj2` и класса останется `5`.

**Правильный ответ:** Г

**4. Каким будет вывод следующего кода?**
```python
class Test:
    attr = 10

    def __init__(self):
        self.attr = 20

obj = Test()
print(obj.attr)
print(Test.attr)
```

А) `20` и `20`  
Б) `10` и `10`  
В) `20` и `10`  
Г) Ошибка, так как атрибут класса переопределён.

**Правильный ответ:** В
