### Практическое задание №1

Создайте класс `Cat`, который:
1. В `__init__` принимает `name` и `color`;
2. Внутри конструктора атрибуты:
- `name`
- `color`
- `hunger` (целое число, по умолчанию 50)
3. Добавьте метод `meow()`, который выводит "Мяу!";
4. Добавьте метод `feed(amount)`, который уменьшает атрибут `hunger` (если он есть) на `amount`, но не ниже 0 (если `hunger - amount < 0`, устанавливайте `hunger = 0`);
5. Добавьте метод `is_hungry()`, который возвращает `True`, если `hunger > 20`, иначе `False`;
6. Добавьте атрибут класса `species = "кот"`;
7. Добавьте метод класса `get_species()` (с декоратором `@classmethod`), который возвращает значение атрибута класса `species`.

Проверьте работу всех методов на примере создания объекта (экземпляра класса) и вызова каждого метода.

### Практическое задание №2

Создайте базовый класс `Animal`, который:
1. В `__init__` принимает `name` и `species`;
2. Внутри конструктора создает атрибуты:
- `name` публичный (public)
- `_species` защищенный (protected) (инициализируется переданным значением)
- `__age` приватный (private) (инициализируется значением `0`)
3. Реализует методы:
- `get_age()` - возвращает текущий возраст
- `set_age()` - устанавливает возраст (с проверкой, что `age > 0`, если `age <= 0`, выводит сообщение об ошибке и не меняет возраст)
- `voice()` - выводит на экран `"Звук"`;

Создайте класс `Cat` (наследник `Animal`), который:
1. В `__init__` принимает `name` и `color`;
2. Вызывает `super().__init__(name, species="Кошка")`;
3. Переопределяет метод `voice()` и выводит `"Мяу!"`;
4. Содержит уникальный метод `purr()`, который выводит `"Мур-мур..."`

Создайте класс `Dog` (наследник `Animal`), который:
1. В `__init__` принимает `name` и `breed`;
2. Вызывает `super().__init__(name, species="Собака")`;
3. Переопределяет метод `voice()` и выводит `"Гав!"`.

Проверьте работу, создав экземпляры классов и продемонстрировав:
- Создание кота (имя, цвет, вид);
- Создание собаки (имя, порода, вид);
- Вызов методов voice() и purr() (только для кота);
- Установку и получение возраста через методы;
- Попытку установить некорректный возраст (отрицательный).
