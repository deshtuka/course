# Тема 2. Классы и объекты.

Вспомним вводную часть и поставим **задачу:** Создать **единую форму (шаблон)**, по которой будут создаваться все наши животные. Эта форма гарантирует, что у каждого животного **обязательно** будут имя, возраст и пустой желудок. Ничего не забудем, ничего не перепутаем.

Такой шаблон в Python называется **классом**. А каждое конкретное животное, созданное по этому шаблону, — **объектом** (или экземпляром).

### 1. Определение класса
Класс объявляется ключевым словом `class`. Имя класса принято писать с большой буквы (CamelCase).

```python
class Animal:
    pass   # временно пусто
```

Но нам нужно, чтобы при создании животного мы сразу указывали его имя и возраст. Для этого существует специальный метод **`__init__`** (читается как «инит», а называется конструктор/инициализатор). Он вызывается автоматически в момент создания объекта и настраивает его начальные данные.

```python
class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.favorite_food = []
```

**Разберём, что здесь написано:**

- `__init__` — это **магический метод**, который автоматически запускается при рождении объекта. Пока мы просто запомним, что он нужен для установки начальных значений.
- `self` — это ссылка на **создаваемый объект**. Он всегда пишется первым параметром (но при вызове мы его не передаём — Python подставляет его сам).
- `name` и `age` — это параметры, которые мы **обязаны** передать при создании.
- Внутри мы пишем `self.name = name` — это означает: «возьми переданное имя и сохрани его внутри объекта под именем `name`». То же самое с возрастом и желудком.

> **Важно:** `self` — это просто соглашение.

### 2. Создание объектов (экземпляров)

Теперь мы можем создавать сколько угодно животных:

```python
animal1 = Animal("Симба", 5)
animal2 = Animal("Кеша", 2)
```

Что произошло в момент вызова `Animal("Симба", 5)`?
1. Python создал новый пустой объект.
2. Вызвал у этого объекта метод `__init__`, передав туда `self` (этот самый объект), `"Симба"` и `5`.
3. Внутри `__init__` у объекта появились три «ячейки»: `name`, `age`, `favorite_food`.

Теперь мы можем обратиться к этим данным через точку:

```python
print(animal1.name)             # Симба
print(animal2.age)              # 2
print(animal1.favorite_food)    # []
```

Каждый объект хранит **свои собственные** значения. Изменение `animal1.name` не повлияет на `animal2`.

---

### 3. Класс и объект — в чём разница?

- **Класс** (`Animal`) — это **чертёж**, описание того, из чего состоит животное и как оно создаётся. Он существует в коде в единственном виде.
- **Объект** (экземпляр) — это **конкретный экземпляр**, созданный по чертежу. У него есть собственные данные. Объектов может быть множество.

Можно проверить типы:

```python
print(type(animal1))      # <class '__main__.Animal'>
print(type(Animal))       # <class 'type'> (это пока не важно)
```

Теперь мы **гарантированно** знаем, что у каждого объекта есть `name`, `age` и `favorite_food`. Забудем что-то — Python сразу выдаст ошибку, потому что у класса нет такого поля.

---

### Распространенные ошибки

| Ошибка                                      | Пояснение                                                                       | Решение                                                              |
|---------------------------------------------|---------------------------------------------------------------------------------|----------------------------------------------------------------------|
| Забыли `self` в параметрах метода           | Python выдаст ошибку, потому что метод должен принимать объект                  | Всегда пишите `self` первым параметром                               |
| Используют `self` вне метода                | `self` имеет смысл только внутри методов класса                                 | Там, где нужно обратиться к атрибуту объекта, используйте `self.имя` |
| Пытаются вызвать метод без создания объекта | Нельзя написать `Animal.feed("мясо")` — это метод экземпляра                    | Сначала создайте объект: `a = Animal(...); a.feed("мясо")`           |
| Путают `__init__` и обычный метод           | `__init__` вызывается автоматически при создании, его не нужно вызывать вручную | Не вызывайте `obj.__init__()` сами — это сделает Python              |

### Краткий итог

- Класс — это шаблон, а объект — конкретная сущность.
- Мы научились объявлять класс с методом `__init__`, который задаёт начальные атрибуты.
- Мы научились создавать объекты и обращаться к их данным через точку.

### Тестовые задания

**1. Что такое класс в объектно-ориентированном программировании?**  
А) Конкретный экземпляр данных, имеющий состояние и поведение.  
Б) Шаблон (чертёж) для создания объектов, описывающий их структуру и методы.  
В) Функция, которая возвращает новый объект.  
Г) Переменная, хранящая ссылку на метод.

**Правильный ответ:** Б

---

**2. Для чего используется параметр `self` в методах класса?**  
А) Для обращения к глобальным переменным модуля.  
Б) Для передачи аргументов в метод извне.  
В) Для ссылки на текущий экземпляр класса и доступа к его атрибутам и методам.  
Г) Для объявления статических методов.

**Правильный ответ:** В

---

**3. Как обратиться к атрибуту `name` объекта `obj` _внутри метода_ этого же класса?**  
А) `name`  
Б) `obj.name`
В) `self->name`  
Г) `self.name`

**Правильный ответ:** Г

---

**4. Что произойдёт при выполнении кода:**  
```python
class A:
    def __init__(self, x):
        self.x = x
a = A(5)
print(a.x)
```  
А) Ошибка, потому что атрибут `x` не объявлен явно.  
Б) Будет выведено `5`.  
В) Будет выведено `None`.  
Г) Ошибка, так как `self` не определён вне метода.

**Правильный ответ:** Б
